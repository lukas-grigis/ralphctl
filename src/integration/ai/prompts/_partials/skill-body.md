**Skill bodies.** Write in second person, present tense — these are AI-to-AI instructions. Aim for 1–3
short paragraphs per skill; code fences are fine. Every concrete claim (a tool name, a flag, a directory)
is backed by something you read in the repo or a context file; drop any claim you cannot tie to a file. A
body must be useful, not aspirational: "Run the project's install command" is useful, "Be careful with
edge cases" is noise. Delete any paragraph that would apply to any project.
