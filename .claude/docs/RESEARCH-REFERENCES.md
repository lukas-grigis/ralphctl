# Research References

Every external source the prompt layer and harness design rest on, with what each one actually
establishes, where it is used, and its verification status. All entries below were verified against the
live originals on **2026-07-26/27** (existence, authorship, and claim fidelity checked by fetching each
source; attribution defects found in that audit have been fixed in the citing files).

Maintenance rules:

- A claim cited anywhere in `src/` or `.claude/` should have a row here — add the row when adding the
  citation, with a URL or arXiv ID. URL-less citations are how fabricated references slip in.
- Descriptive findings (what files/agents typically look like) must not be cited as prescriptive
  recommendations — say "informed by", not "recommends", unless the source actually recommends.
- Re-audit on model bumps: several rows encode model-capability assumptions (long-context behaviour,
  judge reliability) that shift with each generation.

## Evaluated and NOT adopted

Kept here so the reasoning is findable before anyone re-proposes them.

| Idea                                                 | Source                                                              | Why not (as of 2026-07)                                                                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Best-of-N parallel generation + tournament selection | [arXiv 2604.16529](https://arxiv.org/abs/2604.16529)                | Real gains, wrong cost profile as a default; candidate future opt-in escalation-ladder rung                                             |
| Evaluator writes throwaway probe tests               | [UTGen/UTDebug, arXiv 2502.01619](https://arxiv.org/abs/2502.01619) | Needs a permission-surface review first (write carve-out beyond `signals.json`); adopt only if manual-criterion false verdicts observed |
| Rubric-order shuffling per round                     | [arXiv 2602.02219](https://arxiv.org/abs/2602.02219)                | Evidence is for score-scale rubrics; unproven for binary + mandatory-evidence grading                                                   |
| Multi-judge ensembles / debate                       | [arXiv 2604.23178](https://arxiv.org/abs/2604.23178)                | Measured wins are style-bias-dominated preference judging; execution-grounded code grading barely touches those biases; 2–3× cost       |
| Numeric per-criterion confidence scores              | —                                                                   | No calibration evidence found; would dilute the binary contract                                                                         |
| Vector / graph memory retrieval                      | MAGMA/MemoryOS class                                                | Headline numbers secondhand, chat-assistant workloads; tiered selection + JIT file re-read covers the need with zero infra              |
| Haystack shuffling of progress excerpts              | [Context Rot (Chroma)](https://research.trychroma.com/context-rot)  | Verified effect, but destroys human auditability and the depth guarantee; mechanism unexplained                                         |
| Exposing attempt budget to the generator             | —                                                                   | No published evidence; plausible corner-cutting failure mode                                                                            |
| Learning age-decay + `supersedes` lifecycle          | [ACE, arXiv 2510.04618](https://arxiv.org/abs/2510.04618)           | Worth doing (anti context-collapse) but a contract/composer change — ticket, not a drive-by edit                                        |
| Per-section context-composition telemetry            | [LOCA-bench, arXiv 2602.07962](https://arxiv.org/abs/2602.07962)    | Prerequisite for tuning caps honestly; harness code change — ticket                                                                     |
| Episode auto-consolidation after ≥3 attempts         | [arXiv 2605.17625](https://arxiv.org/abs/2605.17625)                | Only matters for high-attempt tasks; defer until telemetry shows attempt histories being lost                                           |
